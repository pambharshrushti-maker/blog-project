# 📝 React Blog Project

A simple and responsive Blog Website built using **React.js** and **Bootstrap**.

## 🚀 Features

* 🏠 Home Page
* 📰 Latest Blogs
* ✍️ My Blogs
* 📱 Responsive Design
* 🎨 Bootstrap UI
* 🔗 Easy Navigation

## 🛠️ Technologies Used

* React.js
* JavaScript
* Bootstrap
* HTML
* CSS

## 📂 Project Structure

```text
src/
├── components/
├── pages/
├── App.jsx
├── App.css
└── main.jsx
```

## ▶️ How to Run

First install the required packages:

```bash
npm install
```

Then start the project:

```bash
npm run dev
```

Open the localhost link shown in the terminal.
